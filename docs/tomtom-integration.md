# TomTom maps

Production uses TomTom whenever NEXT_PUBLIC_TOMTOM_API_KEY is set to a valid key. Existing account coordinates, pins, colors, filters and boundaries remain unchanged. Map display uses the Orbis v2 raster API through the existing Leaflet renderer, without the retired TomTom Web SDK. A Traffic toggle requests current flow tiles only when enabled. A base-tile error switches visibly to OpenStreetMap.

Enable Map Display API, Geocoding API, Places Search API and Routing API; Traffic API enables the flow overlay. Restrict this public browser key to the application domains. Server requests use the same configured key and a fixed https://reppilot.app referrer/origin, never a request-supplied origin. Do not remove the domain whitelist to make server calls work. Google remains available when TomTom is not configured; a TomTom API error is reported rather than silently rerunning a potentially billable Google call.

Geocoding, office discovery and live-traffic driving times run behind the existing authenticated server actions, tenant controls, trial enforcement and search/route rate limits. Search results require a provider-returned name, complete US street address and valid coordinates before users can choose to add them. No sample offices or approximate drive times are invented. Queries, address fields and route coordinates are sent to TomTom; the privacy notice names TomTom.

Office discovery is a provider search, not a verified healthcare directory. Use a specific practice name and city, or a specialty with the map centered in the desired area. Users review results before adding an account. Live smoke checks returned Cook Children's offices in Frisco and nearby pediatrics, valid Plano address coordinates, a road-route duration, base tiles and traffic tiles using the configured key. Tests cover coordinate order, incomplete addresses, missing durations, invalid inputs, absent keys and upstream failures. Signed-in visual verification is still needed; the live API checks do not constitute a browser acceptance test.

External navigation links continue opening Google Maps; those are ordinary links and do not use the Google Maps API key. Suggested stop ordering still uses the existing straight-line logic; TomTom calculates road distances and live-traffic durations for that order. This change does not add traffic-based stop-order optimization.

## Specialty searches and saving results

Broad Pediatrician/Pediatricians queries map to the provider term pediatrics; named practices are retained. The visible rectangle is sent as a provider filter before ranking, not merely filtered after a global result set is returned. Search remains capped at 100 provider results and does not guarantee directory completeness. Complete duplicate office results are collapsed by normalized name, street and ZIP. Results are available in one scrolling sidebar and through map popups; both offer an editable specialty and Add to my accounts. Saving creates the account, assignment and audit record in one transaction, refreshes account data and stays on the map. Duplicate-office errors are shown without claiming the office was assigned to the current user.
