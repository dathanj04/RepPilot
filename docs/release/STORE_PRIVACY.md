# Store privacy answers

Prepared November 8, 2026 for Johnson Strategic Outreach and Solutions DBA Rep Pilot LLC. Support and privacy contact: dathan@abagrowth.com. Paste these into App Store Connect and Play Console. They describe this version only. CRM referral sync and card billing are not in this version. Do not declare them as collected or as working features.

## Apple App Privacy

| Data type | Collected | Linked to identity | Used for tracking | Purpose |
| --- | --- | --- | --- | --- |
| Name, email, phone | Yes | Yes | No | App functionality, customer support |
| Precise location | Only if the person allows it | Yes | No | App functionality (maps and routes) |
| Photos or files | Only when a receipt is uploaded | Yes | No | App functionality |
| User content (visit notes, messages) | Yes | Yes | No | App functionality |
| Product interaction | Yes, as security audit records | Yes | No | App functionality, security |
| Other diagnostic data | Only if an error monitor is configured | No | No | App functionality |

Tracking: no. Third-party advertising: no. Data sold: no.

Optional sharing, only when that provider is configured and the person uses the feature: Resend (email content), Google Maps (addresses and routes), Google Gemini (briefing text), Google Calendar or Microsoft 365 (calendar the person connects). Say so in the privacy policy link: the public `/privacy` page.

Account deletion: in-app under Settings → Delete account, and on the web at `/delete-account`.

## Google Data safety

- Data is encrypted in transit.
- Users can request deletion. The app deletes the account.
- Data is not sold.
- Data collected: name, email address, phone number (optional), app interactions, user-generated content, approximate or precise location (optional), files (optional receipts).
- Data shared with service providers only to run the feature the person used. No advertising SDK.
- CRM and payments: not collected, because those features are not active.

## Listing claims to avoid

Do not write that RepPilot orders catering, charges a card, syncs Salesforce or HubSpot referrals, or is HIPAA certified. Maps work without a Google key. Drive time, live email, and calendar sync appear only after those providers are connected.
